# Trigo Delicias Web

Criar o site institucional da padaria Delícias do Trigo baseado na estrutura de referência da Doce Sonho Padaria (https://www.docesonhopadaria.com.br/). Mudar o nome da padaria para Delícias do Trigo. Fazer uma apresentação institucional destacando o espaço acolhedor, a variedade de produtos (pães artesanais, confeitaria fina, cafés especiais, salgados e café da manhã), galeria de fotos do ambiente e produtos, e informações práticas completas (horários de funcionamento, localização com mapa, telefone e contato via WhatsApp).
